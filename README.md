# Zhanqiu (Jack) Guo - Academic Homepage

This repository contains the source for Zhanqiu (Jack) Guo's academic homepage, built with the Academic Pages Jekyll template and configured for GitHub Pages at:

https://zhanqiu-guo.github.io

## Local Preview

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

The local site will be available at `http://localhost:4000`.

## GitHub Pages Deployment

Create a public GitHub repository named `Zhanqiu-Guo.github.io`, then push this repository to its `main` branch. GitHub Pages will publish the site at `https://zhanqiu-guo.github.io`.
