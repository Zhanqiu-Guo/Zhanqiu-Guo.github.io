DynaMem constructs an online dynamic spatio-semantic memory for open-world mobile manipulation. It maintains dynamic 3D point-cloud memory and answers open-vocabulary object localization queries using multimodal LLMs or open-vocabulary vision-language features.

The system achieved 70% average pick-and-drop success on non-stationary objects, more than 2x better than static systems. Project website: [dynamem.github.io](https://dynamem.github.io/).
